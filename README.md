# Social Media Sentiment Analysis

## Project Overview
Social Media Sentiment Analysis is a data analytics project developed using Python and Streamlit. It analyzes social media posts to understand public sentiment, emotions, engagement, trending topics, toxicity and spam.

## Objectives
- Analyze positive, negative and neutral sentiments.
- Understand emotions in social media posts.
- Compare engagement across different platforms.
- Identify trending topics.
- Analyze toxicity and spam.
- Present meaningful insights through visualizations.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Streamlit

## Dashboard Features
- Executive Dashboard
- Dataset Overview
- Sentiment Analysis
- Emotion Analysis
- Platform Analysis
- Engagement Analysis
- Trending Topics
- Toxicity & Spam Analysis
- Key Insights

## Project Files
- `app.py` – Main Streamlit application.
- `Social_Media.csv` – Dataset used for analysis.

## How to Run the Project

**1. Install the required libraries:**

```bash
pip install streamlit pandas numpy matplotlib seaborn
```

**2. Open the project folder in VS Code.**

**3. Run the application:**

```bash
py -m streamlit run app.py
```

**4. Open the local URL displayed in the terminal.**

## Conclusion
This project provides an interactive dashboard to analyze social media data and understand sentiment, emotions and engagement patterns through data visualization.
